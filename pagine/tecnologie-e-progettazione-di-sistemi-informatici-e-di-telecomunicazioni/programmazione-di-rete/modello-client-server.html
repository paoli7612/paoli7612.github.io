Modello client-server

Programmazione di rete

client e server

Nel modello client-server il client richiede un servizio e il server rimane disponibile per ricevere e gestire le richieste.

La separazione dei ruoli permette a più client di utilizzare servizi centralizzati attraverso la rete.

richieste e risposte

Molti protocolli applicativi organizzano la comunicazione come scambio di richieste e relative risposte.

Client e server devono condividere un protocollo che stabilisca formato, significato e sequenza dei messaggi.

server iterativi e concorrenti

Un server iterativo gestisce normalmente una richiesta alla volta, mentre un server concorrente può servire più client contemporaneamente.

Processi, thread o modelli asincroni permettono di implementare differenti strategie di concorrenza lato server.

progettazione del protocollo

Un protocollo applicativo deve stabilire struttura e significato dei messaggi scambiati.

È necessario considerare delimitazione dei messaggi, codifica dei dati, gestione degli errori e chiusura della comunicazione.
