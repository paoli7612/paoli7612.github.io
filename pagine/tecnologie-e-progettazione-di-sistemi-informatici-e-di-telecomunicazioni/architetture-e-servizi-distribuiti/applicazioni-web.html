Applicazioni Web

Architetture e servizi distribuiti

browser e server Web

Il browser svolge il ruolo di client e comunica con il server Web mediante protocolli come HTTP e HTTPS.

Il server riceve le richieste e restituisce risorse statiche oppure risultati generati dinamicamente.

contenuti statici e dinamici

Una risorsa statica viene restituita sostanzialmente nella forma memorizzata sul server.

Un'applicazione dinamica genera invece il contenuto in funzione della richiesta, dei dati e dello stato applicativo.

stato, cookie e sessioni

HTTP è intrinsecamente stateless e non conserva automaticamente informazioni tra richieste successive.

Cookie e sessioni permettono alle applicazioni di mantenere informazioni associate al client tra più richieste.

autenticazione Web

Le applicazioni Web possono richiedere l'identificazione dell'utente prima di concedere l'accesso a determinate risorse.

Autenticazione, sessione e autorizzazione devono essere progettate separatamente e protette da adeguate misure di sicurezza.
