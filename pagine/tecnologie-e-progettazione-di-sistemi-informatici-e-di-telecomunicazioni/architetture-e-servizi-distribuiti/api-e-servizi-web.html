API e servizi Web

Architetture e servizi distribuiti

API

Un'API definisce un'interfaccia attraverso cui un componente software può utilizzare funzionalità offerte da un altro componente.

Le API permettono di integrare sistemi differenti senza conoscere i dettagli interni delle rispettive implementazioni.

servizi Web

Un servizio Web rende disponibili funzionalità applicative attraverso protocolli e formati utilizzabili tramite rete.

Applicazioni differenti possono quindi cooperare scambiandosi richieste e dati secondo interfacce definite.

REST

REST è uno stile architetturale frequentemente utilizzato per progettare servizi accessibili attraverso HTTP.

Le risorse vengono identificate mediante URI e manipolate attraverso operazioni associate ai metodi del protocollo.

JSON e scambio dei dati

JSON è frequentemente utilizzato per rappresentare i dati scambiati tra client e API Web.

Il client serializza e deserializza le informazioni secondo la struttura prevista dal servizio.
