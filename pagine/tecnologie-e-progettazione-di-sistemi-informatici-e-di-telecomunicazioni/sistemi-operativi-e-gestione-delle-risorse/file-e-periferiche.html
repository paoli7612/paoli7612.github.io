File e periferiche

Sistemi operativi e gestione delle risorse

File e directory

Un file è un contenitore di informazioni persistenti: resta memorizzato anche quando il computer viene spento. Puo contenere testo, immagini, audio, video, codice sorgente, dati strutturati o programmi eseguibili. Per l'utente il file ha un nome e spesso un'estensione; per il sistema operativo ha anche metadati come dimensione, data, proprietario e permessi.

Le directory, o cartelle, servono a organizzare i file in una struttura gerarchica. Questa organizzazione permette di trovare i dati, separare progetti, applicare permessi e costruire percorsi chiari.

File system

Il file system è il modo in cui il sistema operativo organizza file e directory su un dispositivo di memorizzazione. Non memorizza solo il contenuto dei file, ma anche informazioni necessarie a ritrovarli e gestirli: nomi, blocchi occupati, permessi, date e struttura delle cartelle.

File system diversi hanno caratteristiche diverse. Alcuni sono pensati per compatibilità con molti dispositivi, altri per affidabilità, sicurezza, grandi dimensioni o prestazioni. Esempi comuni sono NTFS su Windows, ext4 su Linux, APFS su macOS, FAT32 ed exFAT per chiavette e dispositivi removibili.

Operazioni sui file

Quando un programma apre un file, chiede al sistema operativo un canale di accesso. Il sistema controlla i permessi, individua i dati sul dispositivo e restituisce al processo un riferimento. Da quel momento il programma può leggere, scrivere o spostarsi nel file secondo le operazioni consentite.

Questo livello di astrazione è prezioso: lo stesso programma può leggere un file senza conoscere i dettagli fisici dell'SSD, del disco esterno o della memoria di rete. Il sistema operativo nasconde la complessità dell'hardware e offre un'interfaccia uniforme.

Periferiche, driver e interrupt

Le periferiche sono dispositivi di input, output o memorizzazione: tastiera, mouse, monitor, stampante, scheda di rete, webcam, disco, sensori. Ogni periferica ha caratteristiche specifiche e comunica con il computer attraverso controller e bus.

Il driver è il componente software che permette al sistema operativo di controllare una periferica. Le applicazioni non devono conoscere tutti i dettagli del dispositivo: chiedono al sistema operativo di stampare, leggere dati o inviare pacchetti, è il sistema operativo usa il driver corretto.

Gli interrupt permettono alle periferiche di attirare l'attenzione della CPU quando serve. Invece di controllare continuamente se un dispositivo ha finito un'operazione, il processore può svolgere altro lavoro e reagire quando riceve il segnale.

Buffer, cache e prestazioni

Le periferiche spesso sono più lente della CPU. Per evitare sprechi, il sistema operativo usa buffer e cache. Un buffer raccoglie temporaneamente dati in ingresso o in uscita; una cache conserva dati usati di frequente per recuperarli più rapidamente.

Quando copi un file grande, guardi un video o scarichi dati dalla rete, il sistema operativo coordina memoria, disco, driver e processi. L'utente vede un'operazione semplice, ma sotto ci sono molte componenti sincronizzate.
