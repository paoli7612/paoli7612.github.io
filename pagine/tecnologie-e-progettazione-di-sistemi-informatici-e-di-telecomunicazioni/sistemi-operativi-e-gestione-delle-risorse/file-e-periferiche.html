File e periferiche

Sistemi operativi e gestione delle risorse

file e directory

I file permettono di memorizzare informazioni persistenti, mentre le directory consentono di organizzarli gerarchicamente.

Il sistema operativo fornisce operazioni per creare, leggere, modificare, spostare ed eliminare file e directory.

file system

Il file system definisce come dati e metadati vengono organizzati sui dispositivi di memorizzazione.

Differenti file system offrono caratteristiche relative a dimensioni, permessi, affidabilità e compatibilità.

dispositivi di I/O

Il sistema operativo coordina l'accesso alle periferiche di input/output evitando che le applicazioni debbano controllare direttamente l'hardware.

Buffer, code e interrupt permettono di gestire dispositivi caratterizzati da velocità e modalità operative differenti.

driver

I driver costituiscono il livello software attraverso cui il sistema operativo controlla specifiche periferiche.

Permettono alle applicazioni di utilizzare dispositivi differenti attraverso interfacce relativamente uniformi.
