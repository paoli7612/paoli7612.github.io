Architettura dell'applicazione

Applicazioni Web e basi di dati

presentazione

Il livello di presentazione gestisce l'interazione con l'utente e la visualizzazione delle informazioni.

Nelle applicazioni Web comprende principalmente pagine, componenti dell'interfaccia e codice eseguito nel browser.

logica applicativa

La logica applicativa implementa le regole e le operazioni specifiche del problema affrontato.

Separarla dalla presentazione e dalla persistenza rende il software più semplice da verificare e modificare.

persistenza

Il livello di persistenza gestisce l'accesso ai dati memorizzati.

Centralizzare l'interazione con il database evita di distribuire query e dettagli del DBMS in tutta l'applicazione.

integrazione client-server-database

Una tipica applicazione Web combina interfaccia client, logica eseguita sul server e dati persistenti gestiti da un DBMS.

Comprendere il percorso completo richiesta-elaborazione-query-risposta permette di progettare e diagnosticare l'intero sistema.
