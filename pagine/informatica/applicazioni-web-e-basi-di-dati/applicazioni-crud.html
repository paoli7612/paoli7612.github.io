Applicazioni CRUD

Applicazioni Web e basi di dati

Create

L'applicazione permette di acquisire nuovi dati dall'utente e inserirli nel database.

Gli input devono essere validati e trasformati nella rappresentazione prevista dal modello dei dati.

Read

Le operazioni di lettura interrogano il database e presentano i dati selezionati.

Filtri, ricerca, ordinamento e paginazione permettono di gestire insiemi di informazioni più ampi.

Update

Le operazioni di aggiornamento modificano dati già presenti nel database.

L'applicazione deve individuare correttamente l'entità interessata e verificare la validità dei nuovi valori.

Delete

Le operazioni di eliminazione rimuovono dati secondo le regole previste dal sistema.

Vincoli e relazioni tra tabelle devono essere considerati per preservare l'integrità referenziale.
