Programmazione lato server

Applicazioni Web e basi di dati

server-side scripting

Il codice lato server viene eseguito sul server in risposta alle richieste provenienti dai client.

Può elaborare dati, applicare la logica dell'applicazione e generare dinamicamente la risposta da inviare al browser.

richiesta e risposta

L'applicazione server riceve informazioni attraverso metodo, percorso, parametri, header e corpo della richiesta HTTP.

Produce una risposta contenente codice di stato, header e contenuto destinato al client.

parametri e form

I dati inseriti nei form possono essere inviati al server attraverso richieste HTTP.

L'applicazione deve acquisire e validare gli input prima di utilizzarli nelle elaborazioni.

sessioni

Le sessioni permettono di mantenere informazioni relative a un utente attraverso richieste HTTP differenti.

Sono utilizzate, ad esempio, per autenticazione, preferenze e dati temporanei associati all'interazione.
