File e formati strutturati

Organizzazione e gestione dei dati

file di testo e binari

I file permettono di conservare informazioni in modo persistente oltre la durata di esecuzione del programma.

I file di testo rappresentano dati mediante caratteri, mentre i file binari utilizzano sequenze di byte interpretate secondo uno specifico formato.

lettura, scrittura e accesso

Un programma può aprire un file in differenti modalità per leggerne, crearne o modificarne il contenuto.

È necessario gestire correttamente apertura, posizione, codifica, errori e chiusura delle risorse.

CSV, JSON e XML

CSV, JSON e XML sono formati utilizzati per rappresentare e scambiare dati strutturati.

CSV è particolarmente adatto a dati tabellari, mentre JSON e XML possono rappresentare strutture gerarchiche più articolate.

serializzazione

La serializzazione converte dati o oggetti in una rappresentazione memorizzabile o trasmissibile.

La deserializzazione ricostruisce dalla rappresentazione persistente le strutture utilizzabili dal programma.
