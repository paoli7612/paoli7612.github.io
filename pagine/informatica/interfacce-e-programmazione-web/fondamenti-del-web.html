Interfacce e programmazione Web

HTML

HTML descrive la struttura semantica dei documenti e delle pagine Web attraverso elementi e attributi.

Titoli, paragrafi, collegamenti, immagini, liste, tabelle e form permettono di organizzare contenuti e interazioni.

CSS

CSS definisce presentazione e disposizione degli elementi HTML separando struttura e aspetto della pagina.

Selettori, proprietà, box model e sistemi di layout permettono di realizzare interfacce Web adattabili.

form

I form permettono di acquisire dati dall'utente attraverso controlli come campi, selezioni e pulsanti.

I dati inseriti possono essere elaborati dal client oppure inviati a un'applicazione lato server.

struttura e accessibilità

Una corretta struttura semantica rende le pagine più comprensibili a browser, motori e tecnologie assistive.

La progettazione deve considerare navigabilità, leggibilità e utilizzo attraverso dispositivi e utenti differenti.
