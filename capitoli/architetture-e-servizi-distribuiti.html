Architetture delle applicazioni

Un'applicazione monolitica concentra gran parte delle funzionalità in un unico sistema, mentre un'applicazione distribuita suddivide responsabilità tra più componenti.

Applicazioni Web

Il browser svolge il ruolo di client e comunica con il server Web mediante protocolli come HTTP e HTTPS.

API e servizi Web

Un'API definisce un'interfaccia attraverso cui un componente software può utilizzare funzionalità offerte da un altro componente.

Distribuzione e gestione delle applicazioni

Un'applicazione dipende da sistema operativo, runtime, librerie, configurazioni e servizi esterni necessari alla sua esecuzione.
